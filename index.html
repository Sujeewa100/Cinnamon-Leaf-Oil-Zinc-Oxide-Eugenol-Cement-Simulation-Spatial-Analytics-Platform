💻 Automated R Reproducibility Script

Ready-to-run R script for the research team to execute batch analysis with publication formatting: 

# Cinnamon Leaf Oil ZOE Cement Analysis
library(tidyverse)
library(car)
library(emmeans)

# 1. Load Experimental Matrix
df <- read.csv("clo_zoe_experiment_data.csv")

# 2. Factorial Two-Way ANOVA
fit <- aov(Compressive_Strength ~ PL_Ratio * Temperature, data = df)
summary(fit)

# 3. Tukey Post-Hoc Pairwise Comparisons
posthoc <- emmeans(fit, pairwise ~ PL_Ratio, adjust = "tukey")
print(posthoc$contrasts)

# 4. Reaction Kinetics Modeling (Setting Velocity)
fit_kinetics <- nls(Hardness ~ H_max * Time^n / (K^n + Time^n),
                    data = df, start = list(H_max = 30, K = 5, n = 2))
summary(fit_kinetics)
